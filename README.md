# БТЖТиС: система контроля учебного процесса

Веб-приложение на `Python + Django` для автоматизации тестирования, контроля успеваемости и управления учебным процессом в БТЖТиС.

## Что реализовано

- ролевая модель: студент, преподаватель, администратор
- регистрация, вход и смена пароля
- личные кабинеты для трёх ролей
- профиль пользователя с редактированием персональных данных
- управление учебными группами и дисциплинами
- конструктор тестов с вопросами, изображениями и вариантами ответов
- прохождение теста студентом с таймером и автосохранением ответа
- автоматическая проверка, итоговый результат и история попыток
- аналитика преподавателя и журнал действий администратора
- Django admin по адресу `http://127.0.0.1:8000/django-admin/`

## Запуск проекта

1. Установить зависимости:

```bash
python -m pip install -r requirements.txt
```

2. При необходимости настроить MySQL через переменные окружения из файла `.env.example`.

3. Выполнить миграции:

```bash
python manage.py makemigrations
python manage.py migrate
```

4. Создать администратора:

```bash
python manage.py createsuperuser
```

5. Запустить сервер:

```bash
python manage.py runserver
```

## База данных

Проект настроен на работу с MySQL через `PyMySQL`. Если переменные `MYSQL_DB`, `MYSQL_USER` и `MYSQL_PASSWORD` не заданы, приложение автоматически использует SQLite как локальный fallback для быстрого запуска и проверки интерфейса.
